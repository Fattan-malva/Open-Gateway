Open Gateway

Siap. Bot memakai model yang dipilih di tab Gateway, memanggil provider lewat /chat/completions, lalu membalas di Discord dengan riwayat percakapan per channel.

Dua menu, alur yang jelas.

Atur sumber model di AI Provider, lalu tentukan bagaimana model itu hidup di Discord.

AI Provider

Simpan Base URL dan API key OpenAI-compatible. Semua model dari endpoint /models langsung tampil dan bisa dicari.

Gateway Discord

Tempel token bot, pilih model, dan atur pemicu balasan: mention, DM, prefix, atau semua pesan di satu channel.

Riwayat per channel

Bot mengingat konteks percakapan di tiap channel dengan batas riwayat yang bisa kamu atur. !ai reset membersihkannya.

Lokal & privat

Server hanya berjalan di localhost. Token dan API key disimpan di folder data di mesinmu, bukan di cloud.

Menjalankan dalam tiga langkah.

Satu perintah menjalankan server dan web UI. Bot ikut menyala otomatis bila token sudah tersimpan.

  1. Jalankan server py main.py lalu buka http://127.0.0.1:8787. Halaman aplikasi ada di /app.
  2. Hubungkan provider Di tab AI Provider, isi Base URL dan API key. Klik Simpan & muat model untuk mengambil seluruh daftar model.
  3. Nyalakan bot Di tab Gateway, tempel token bot Discord, pilih model, atur pemicu, lalu tekan Start. Aktifkan Message Content Intent di Developer Portal.
