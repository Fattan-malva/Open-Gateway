Fitur Cara kerja Buka app

DeepSeek web gateway untuk klien OpenAI-compatible

Pakai DeepSeek dari editor dan terminal Anda.

open-masking mengirim pesan ke chat.deepseek.com lewat profil Chrome yang sudah login, lalu menyajikannya sebagai endpoint /v1 yang kompatibel dengan OpenAI. Tanpa API key DeepSeek.

Buka playground Lihat cara kerja
http://127.0.0.1:8787/v1/chat/completions
Tulis fungsi Python untuk membaca file JSON dengan aman.

Fungsi berikut menangani file yang tidak ada dan JSON yang rusak:

import json
from pathlib import Path

def read_json(path):
    try:
        return json.loads(Path(path).read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError):
        return None

Satu endpoint, banyak klien.

Klien Anda tidak perlu berubah. Ganti base URL dan pakai API key lokal, selesai.

Kompatibel OpenAI

Endpoint chat/completions dengan streaming. OpenCode, VS Code, dan curl bisa langsung memakainya.

Reasoning terpisah

Mode thinking diatur per permintaan. Proses berpikir tampil sebagai blok terpisah di playground.

API key terkelola

Buat, beri nama, dan cabut key kapan saja. Nilai key disimpan sebagai hash SHA-256.

Sesi browser terkendali

Profil Chrome khusus gateway. Login sekali, lalu chat bisa berjalan headless.

Tiga langkah ke klien pertama.

Semua pengaturan ada di app. Tidak ada berkas yang harus diedit secara manual sebelum pengujian.

  1. Login Buka tab Browser, tekan Login, lalu selesaikan masuk ke DeepSeek di jendela Chrome.
  2. Buat key Di tab API Keys, buat satu key untuk setiap klien agar mudah dicabut jika diperlukan.
  3. Hubungkan Salin konfigurasi dari tab Connect ke opencode.json, pengaturan VS Code, atau perintah curl. 
curl http://127.0.0.1:8787/v1/chat/completions \
  -H "Authorization: Bearer sk-ds-GANTI_DENGAN_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"Halo"}]}'
